# 事实核查纪律

这个账号做的是真人真事的知识卡片，一旦发布，评论区会有懂行的读者较真挑错。核实的严格程度要比一般自媒体高一档。

## 硬规则

1. **重大声称（去世/获奖/重大事件）必须多方权威信源交叉确认才能采用**，绝不能凭训练数据的旧印象默认为真，也不能因为任务描述里说"某人去世了"就直接假设成立往下做。先核实，核实通过（至少两个独立媒体+官方声明/权威数据库）才敢继续，核实不通过要在第一时间明确告知"这条消息未经证实"。
   - 反面案例（正面教材）：2026-07-27 东野圭吾去世的任务，第一步先用 NHK、日经新闻、讲谈社官方声明三方交叉确认死讯真实性，才开始做卡片。
2. **具体数字（估值、销量、引用量、评测分数）如果不同信源冲突，只用交叉验证过的那一组数字，不要东拼西凑。** 拼凑不同口径的数字（比如"投前估值"和"投后估值"混用、把不同评测体系的分数放在一起对比）是最容易被专业读者挑错的地方。
   - 反面案例（已纠正）：杨植麟系列曾把"$31.5 billion"错误理解为"3150亿人民币"，把不同榜单（LMArena 前端代码盲测 vs DesignArena 3D设计榜单）的分数混着引用。
3. **引语只用查证过的真实原话，标清楚出处（媒体名+年份）**，网络流传的"金句合集"要溯源到一手采访，找不到一手出处的要么不用，要么明确标注"据传/网络流传，未核实到一手来源"。
   - 反面案例（已纠正）：杨植麟"雪山没有尽头"是网络二次概括，原话其实是"前面有延绵的雪山，你不知道里面是什么，但你一步一步往前走"——用原话不用概括版。
4. **论文/成果的作者身份、贡献程度要精确**，一作二作不能混淆，"解决了某问题的一部分"不能夸大成"完全解决了这个世纪难题"。
   - 反面案例（已纠正）：邓煜的希尔伯特第六问题成果，准确说法是"解决了狭义表述中的关键一段逻辑链条"，不是"完全解决了希尔伯特第六问题"；杨植麟在 Transformer-XL 是二作、XLNet 才是一作，两者不能混为一谈。
5. **发言人要对应准确**，不要把联合创始人/其他相关人士的话安在主角头上。
6. **性别/身份标签类说法要克制**，"首位XX""史上第X位女性"这类断言，要确认限定语准确（比如"首位中国籍菲尔兹奖得主"不能省略"中国籍"简化成"首位华人"，因为已有其他国籍的华裔得主）。
7. **网传的煽情/猎奇细节（如"寒门逆袭""家庭贫困"）如果和查证结果不符，要弃用改成更真实的叙事**，不要为了"故事性"选择性采信未经证实的说法。
   - 反面案例：王虹"寒门小镇女孩逆袭"的说法已被辟谣（父母是当地中学在编教师），改用"高一年级排名百名开外→夺得最高奖"这个查证属实的反差叙事。

## 执行方法

- 每期正式制作前，先跑一轮专门的调研 Agent，要求：每条重要信息标注信源链接和可靠度（多源确认/单一信源/存疑），单独列一份"高风险信息清单"标注哪些说法不能用、哪些要加限定语。
- 时效性强的选题（当天/近两天的突发新闻），第一步必须先核实"这件事是不是真的、发生在什么时候"，再进入生平/成就调研阶段。
- 制作完成、发布前，把卡片里所有具体数字/人名/年份再逐条对照调研笔记复核一遍，这是"定稿前最后一道关"，不要跳过。
