# 字号、字重与标题规范 · v2.0

## 不可变前提
- 所有正式卡片 **1200×1600px，3:4 竖版**。字号数值以这一画布的 CSS px 为前提；若 CSS 使用缩放视口，应按实际输出像素换算。
- **封面可以有冲击力，内页必须更克制**：标题不能与封面同等级，更不能因为页面空白就放大。
- 禁止 `scaleX`、`font-stretch`、人为改变文字宽高比，禁止为了填满一行做强制两端拉伸。保持字形本来的比例。

## 推荐字号区间（设计起点，非不可变的像素定律）

| 元素 | 推荐范围 | 设计与验收要点 |
|---|---:|---|
| 封面主标题 | 76–100px | 黑色衬线，字重适中偏重；极短标题可经审稿适当放大 |
| 内页主标题 | **52–68px** | 明显小于封面；中等字重，**默认 58–62px** |
| 内页小标题/强调句 | 36–46px | 仅局部强调，不与主标题抢层级 |
| 正文/导语 | **30–38px** | 默认 32–35px，字重 Regular；长段落优先删改 |
| 表格主文 | 28–34px | 行距充分，细线、少底色 |
| 人物简介/关键年份说明 | 28–36px | 优先短句、列表 |
| 图注、出处 | 22–28px | 默认 24–26px，不得因装不下而缩到难读 |
| 顶栏、页码、英文辅助 | 20–26px | 辅助性信息，确保手机端仍可辨认 |

区间是优先采用的建议上下界，特殊内容可经过单页手机端核对后例外调整；不能机械地为了对齐把某些字形挤窄/变形。旧 `.h-xl { font-size:86px }` 仅属于旧模板，**不得作为内页默认字号**；旧版「正文必须 >=42px」已失效。

## 字重与行距
- 封面：衬线 Bold/Semibold 皆可，视觉冲击来自构图，不靠无限加粗或拉大。
- 内页标题：Medium/Semibold，不能每张都用超黑超粗。长标题可以先精简，再自然换两行。
- 正文：Regular，建议行高约 1.5–1.7；短表格/清单按内容调节。勿用粗体堆叠正文。
- 采用低饱和度强调色、小面积点缀；主标题一般纯黑，深灰正文可略轻。

## 拥挤时的处理顺序
1. 删除重复描述、无根据的总结和非必要元素。
2. 调整自然断句，分段、信息顺序、段距和留白。
3. 仍拥挤时在推荐范围内微调字号/行距，确保整个系列视觉层级一致。
4. 仍装不下就减少该页信息或重新分配页数（总页数遵循 8–10 张）。
5. 不允许溢出画布、压到图片上、孤字悬挂、字体扭曲。**留白不是问题。**

## 封面 Hook 与断行
封面通常两行：精炼、有对仗、反差或节奏，最好是可独立成立的方法论判断。人物身份放在右侧简介补足，不写成一大串新闻事实。封面字重与大小以统一风格为先，不能为了最大字号牺牲舒适。
- 句号依语义决定：如「少谈风口，多做入口。」可以带句号；不强制加，也不一刀切删。
- 断行必须落在语义边界，禁止拆词、硬挤字、孤字。内页过长优先删词，**不是随意放大或压窄**。
- 编辑凝练的 Hook 不能加引号伪装人物原话；真实引语必须出自可追溯原始资料。
- 公众号配文标题另起角度，与封面不同；人名在前加「｜」，**总长度不超过 20 字符（含标点）**。

## 验收方法
- 合图看八到十页标题层级、蓝/红点缀面积和留白节奏。
- 在最终 1200×1600 单页上核查正文、细线、引用、图注；手机屏幕实际滑动再看一遍。
- 验证文本容器未超出安全边距；浏览器截图不会修复本来就被拉伸或裁切的字体。
