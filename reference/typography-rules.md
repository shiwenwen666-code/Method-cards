# 字号与标题规范

这是全系列踩坑最多的一条线（雷军、苏姿丰、东野圭吾、杨植麟都因为字号问题被打回过至少一次）。核心教训：**遇到文字装不下卡片，永远是缩短文案，绝不是调小 font-size。**

## 字号下限表（低于这个数就是不合格）

以 `social-card-leijun`（雷军系列，2026-07 修复过字号问题后的定版）为基准：

| 元素 | class | 下限 |
|---|---|---|
| 正文 | `.body` | 42px |
| 引导段 | `.lead` | 44px |
| 账本标题 | `.ledger-title` | 46px |
| 账本注释 | `.ledger-note` | 38px |
| 人物简介 | `.byline-note` | 38px |
| 图注 | `.img-cap` | 28-29px |
| 引言/大字判断句 | `.pullquote` | 56px 起，能到 60-72px 更好 |
| 卡片小标题 | `.h-xl` | 默认 86px，不要为了塞字往下调 |

**做完一批卡片，专门过一遍所有 `font-size:` 内联覆盖值**，凡是低于上表就要警觉——先尝试砍文案（拆成更短的判断句、去掉从句），不要靠调小字号解决装不下的问题。

## 同一套卡片内，标题字号要视觉统一

一套卡片里经常同时出现两种"标题"写法：`<h2 class="h-xl">`（短语式小标题，默认86px）和 `<p class="pullquote">`（引言式大字，56-76px 不等，因为承载的文字更长）。**这两种即使数值不同，视觉重量也要接近**——如果一张卡的 h-xl 明显比隔壁卡的 pullquote 大一圈，读者会觉得"这一套字号不统一"。做法：pullquote 尽量往 60-72px 靠，只有文字特别长（3 行以上长句）才退到 56-58px。

## 封面大标题：主动做到最大，不要等提醒

1. **先看标题字数选字号**：4-6 字/行可以冲 130-140px；7-8 字/行做到 100-116px；超过 8 字/行说明标题太长，应该先砍句子，而不是把字号往下调。
2. **标题末尾不加句号**（逗号可留，句号删掉能省一个字符位，给字号腾空间）。
3. **人像框主动缩小**：`.byline-portrait` / `.byline-badge` 默认 360px，如果标题字数偏多、人像框和标题挤在一起，主动把宽度缩到 280-300px，把腾出的空间让给标题，不要等被要求了才缩。
4. 标题两行封顶，绝不能因为塞不下而自动换行到第三行——第三行意味着某一行字数超标，必须手动改断句点或砍字。

## 标题内容规范（配合选题方法论的"反常识三关"）

- **标题体裁：方法论金句体，不是叙事/新闻事件体。** 正确的标题读完要像"能直接抄下来当座右铭的处世原则"，句式通常是"A，就B"或"A比B更重要"这类两段式判断句；不能写成"这个人做了什么事/引发了什么反应"这种描述具体事件的句子。从人物本人真实的方法论/名言里提炼（不能编造），把原话压得更短更有韵律。
  - 正例："不想学，就休息够了再学"、"永远把今天，当成第一天"（提炼自贝索斯 Day 1 哲学）、"能活下去，才是硬道理"（提炼自任正非"活下去是企业的硬道理"）。
  - 反例："几乎不接受采访，却缔造了日活10亿的帝国"（这是叙事描述，不是可以摘出来当原则的一句话）。
- 优先用"反常识钩子"：先抛一个悬念/反差事实，人物身份放进封面简介区（byline-note）里补充，不必在大标题里塞满信息。
- 涉及具体金额/分数等敏感对比数据，**标题只陈述事实，不带评价性词汇**（如"垫底""还在路上""不如"这类判断性措辞容易被解读为主观攻击，招致反感/反驳；改用"打败了XX""排名第一"这类可验证的中性陈述句）。
- 女性主角的标题不要拿另一个男性人物的关系当钩子（详见 `topic-selection.md`）。
- 如果封面标题本身就是一句引语（如"不想学，就休息够了再学"），要检查其他内页卡片有没有重复使用同一句话作为标题——重复了就换一个新的角度，被替换下来的那句话可以挪到内文做支撑句。

## 断行细节

- 断句点要落在自然语义停顿处（逗号/短语边界），不要为了凑字数把词组拆开（比如把"就是"拆成两行两半）——这样会触发浏览器的两端对齐拉伸，产生奇怪的空隙，也会破坏词义完整性。
- 遇到"孤字"（最后一行只剩 1-2 个字悬在那里）先检查是不是断句点没选对，能不能把断句往前挪一两个字重新平衡两行长度，而不是直接调小整体字号。
