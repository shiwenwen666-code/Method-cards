# 人物照片来源与筛选

## 来源优先级

1. Wikimedia Commons（免费授权，优先）——用 Commons API 搜索人名/英文名，找 `imageinfo` 里的直连 URL 下载。搜索时多试几种关键词组合（本名、英文名、"人名 + 机构/事件"），常见公众人物往往能找到新闻现场照或官方肖像。
2. 用户直接提供的截图/照片——按用户指定位置放置，不额外加工滤镜（除非用户要求转黑白）。
3. 都找不到时，做一个跟人物成就/学科相关的抽象图形代替（简洁 SVG，不影射任何真实商标/角色形象），并在交付时明确告知用户"未找到免费授权肖像，用了示意图形代替"，不要用不确定授权的图片硬凑。

## 筛选标准

- **默认彩色，不做黑白/duotone**。黑白只在两种情况下用：①人物本身的公众形象/品牌美学就是黑白极简风格（如时尚设计师的个人风格本身如此）②纪念/悼念类主题（黑白更显庄重）。这两种情况也建议先跟用户确认，不要自己默认转黑白。
- 选"好看/有亲和力"的那张：近景优先于舞台远景，表情自然（微笑或专注但不别扭）优先于抓拍到的怪异瞬间，光线均匀，分辨率经得起放大（目标显示宽度 900px 以上不能糊）。
- 如果同一批候选里有好几张，不要图省事选第一张能下载成功的，要真的比较几张选最耐看的一张。
- 明星光环较弱、内容型截图（如访谈视频截图、评测榜单截图、官网截图）不需要遵守"彩色/好看"这条，按原始素材使用即可，重点是配文要跟截图内容对得上（尤其是数据类截图，文案要按截图实际数字重写，不能套用其他来源查到的不同数字）。

## 处理流程（ImageMagick 示例）

```bash
# 人像裁切+对比度增强（保留彩色，不去色）
convert 原图.jpg -crop WxH+X+Y +repage -contrast-stretch 0.3%x0.3% -resize 900x1200 output.jpg

# 需要黑白时才加 -colorspace Gray
convert 原图.jpg -colorspace Gray -contrast-stretch 0.5%x0.5% -resize 900x1200 output_bw.jpg

# 横版图不够宽时，用背景色扩展画布做成横屏（而不是裁切主体内容）
convert 原图.jpg -gravity center -background "#采样到的背景色" -extent 4200x2524 output_landscape.jpg
```

裁切人像时遵循"眼睛落在上三分之一、不切额头"的构图原则，横屏图注意先采样背景色再扩展画布，不要用纯色硬拼接产生违和感。
