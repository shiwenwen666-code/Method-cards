# 发布前检查与交付 · v2.0

## 内容核对
- 人物本人为主线：经历、关键选择、行动、真实结果及方法论边界；不是借人讲空泛励志语。
- 年份、身份、公司节点、获奖、去世、具体数字均根据可靠来源核验。敏感重大断言需官方/权威源及独立交叉核对。
- 原话逐字核实并加“”，紧随人物、媒体/报告/访谈名称与年份；**编辑总结不加引号冒充受访者原话**。出处无法确认就删除该引语。
- 真实图片有来源记录，图注不捏造拍摄时间；许可/署名符合使用条件。
- 封面 Hook 短、有对仗和记忆点；所有内页标题应当是明确观点，不是“为什么是他”式空标题。

## 视觉检查
- **正式所有单页 1200×1600px，3:4 竖版**，8–10 页，页码连续且数量一致，年份正确。
- 封面固定：短 kicker + 两行主标题 + 细线 + 左真人肖像右身份/关键节点 + 底栏。
- 内页标题默认 52–68px、正文 30–38px，字重与字号明显低于封面；超出推荐范围要额外人工核对。整体不拥挤、有留白。
- 禁止标题形变、文字被横向压缩、孤字、溢出、边界裁切、压在图片上、表格破格；不因文字不足放大字体。
- 暖白纸底、小面积低饱和强调色；与既有「审美创意局」案例风格一致。
- 合图看整体；**必须再打开每张高清单页检查**，手机端阅读可辨。尾页只写「审美创意局」落款，无强制长 Slogan。

## 草稿 → 修改 → 定稿
- **草稿**：实际发送 `contact.png` 合图供审核，必要时附单页细节图；未定稿时不提前打包全套。
- **修改**：只改用户点名内容和必要联动项。改动页重新渲染核查；未经要求不要换图/大改结构/改已确定文案。
- **定稿**：用户说 OK、定稿、可以导出后，逐页实际生成 1200×1600 高清文件，依 P01–PXX 提供；当轮要求 ZIP 就打包，否则默认单页。
- **真实性**：没生成文件、未验证路径、未核查图片，就不能说已交付/全部已验收。

## 公众号图文帖配文（不是深度长文）
- 标题格式：`人物姓名｜独立传播 Hook`；总计**20个字符以内（含标点）**，不得重复封面标题。
- 配文为适中的完整叙事，不逐页照搬、不写长论文，也不能太短没有信息。
- 公众号可直接粘贴的**纯文本**：正常换行，段落之间**不插空行**，避免复制后段距过大；不默认使用 Markdown 加粗或分隔线。
- 结尾添加自然关注引导、适量 hashtags（含 `#审美创意局`）；按需要提供建议发布时间。
- 适合中老年读者，文字具体、好懂、有价值，少用空洞营销话术。

## 渲染及环境
使用仓库已有 `template/`、`render.mjs` 与可用 Playwright/Chromium 环境；先检查旧模板的画布与字号设置，并按新规范修改。缺依赖先定位问题，不照搬别的机器绝对路径。程序检查可验证尺寸、页面数、溢出等；图像真实程度、字重、排版精致度和出处可信度仍须人工核查，不可互相替代。
