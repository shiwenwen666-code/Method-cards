# 版式配方 · v2.0

## 统一画布与视觉基因
每页**1200×1600px、3:4 竖版**，一期 8–10 页，编号 P01 到 PXX。统一暖纸白、极细线、黑色中文衬线标题、深灰常规字重正文、低饱和小面积强调色、较宽的边距与克制留白。参考「审美创意局」已经发布的稻盛和夫、于东来、何享健、梁文锋等人物卡片，不另起视觉系统。

## 固定封面 P01
结构：`issue-row → kicker → hgroup（两行黑色主标题）→ rule-accent → cover-byline（左侧真实肖像、右侧身份与履历）→ issue-strip`。
- 封面主标题短、有钩子、语义对仗；合理大但不能变形。末尾标点视句式而定。
- 左肖像使用用户指定真实照片，仅裁切拼贴；不换脸、不二创、不做AI拟真替代。
- 右简介包括姓名、简明身份、2–4个真实关键年份/节点或清晰方法论，不写一大段泛泛形容。
- 照片不压文字；缺可用照片时说明缺口，不擅自换封面样式。
- 底栏放英文名/品牌/年份，年份按该期制作年份，不沿用示例旧年份。

## 内页信息架构
每页只做一件事：**一个观点、一组关键事实、一条可追溯的行动/选择**。8–10 页按内容自然推进，常见叙事为人物简介与时间节点 → 转折/矛盾 → 三四个真实方法 → 反思与结尾。不要机械地每页加“方法论01”或用「为什么是他」等空泛标题。

## 常见版式（按内容选，不能强行凑数量）
- **时间线/账本**：3–6 个节点，以年份、短事件及一行注释排布；年份强调色小面积，行与行留足呼吸。
- **纯文字观点页**：小 kicker → 内页标题 → 两段精简说明 → 可选编辑总结；没有合适照片则纯文字。
- **图文三明治**：标题在上 → 真实图片与图注在中 → 必要说明在下。图片文字不重叠。
- **左右分栏**：仅竖版真实图与短文本适合并列时使用；图片列大小按实际比例安排。
- **对照表**：少行、薄线、浅色或无色表头，手机端清晰，避免大面积饱和色。
- **引语页**：只用核实的逐字原话，以“”包围，紧跟「人物｜作品/媒体或活动｜年份」；提炼判断不冒充引语。
- **尾页**：用简短、观点鲜明的 Hook 收束，可归纳 3–4 条；不要机械写「从某某身上读到的事」。品牌只落款「审美创意局」。

## 字体大小与留白
内页主标题通常 52–68px（优先 58–62px），正文 30–38px，图注 22–28px，详见 `typography-rules.md`。**内页标题小于封面**，字重轻于封面；不要铺满页面、横向压缩文字或为了填空硬加内容。优先减少文字、留下空白。

## 配图与图注
图片只有真实且能证明叙事时才出现。优先用户指定原图，其次经核实授权的公开素材；不生成虚构 QQ 历史界面、不捏造现场照或人物照片。图注格式：`图：画面内容／拍摄时期（确认后填写）；来源：媒体或摄影者／链接或提供者`。资料不足时不要猜拍摄年月或版权归属；可写「用户提供，原始出处待核实」供内部审稿，不将其冒充授权声明。

## 编辑修改
用户指定只改标题字号、字重、图片或色彩时，在原版式和文字基础上做局部修改，其他部分锁定；若确实必须联动排版，明确说明变更范围。避免用重新生图导致整套变味。
