# 版式配方

一套 7-9 张卡片，至少用 5 种不同的版式形状，不要重复。基础规格、渲染流程见 `/workspace/group/审美情报局_知识卡片系统/版式方法论.md`（那份文档管纸墨配色、居中聚拢等基础美学规律，本文档补充"图文混排"这块新增内容）。

## 封面（P1）

结构：`issue-row`（顶部小标签，文字要短，一行内解决，避免和 kicker 内容重复导致换行）→ `hgroup`（kicker + h-display 大标题）→ `rule-accent` 分隔线 → `cover-byline`（左：人像/图标，右：姓名+身份+简介）→ `issue-strip`（底部标签行）。

- `cover-byline` 用 grid 两列，左列人像宽度 280-360px 之间按标题字数动态调整（见 `typography-rules.md`）。
- 找不到真人授权照片时，做一个跟人物成就/学科相关的简洁 SVG 图形代替（例："挂谷猜想"数学家用几何图形、AI 创业者用节点网络图、推理小说家用书本+放大镜），不要为了"有图"随便拼一张不相关的图。

## 内页常见版式

- **纯文字判断句**：`kicker` + `pullquote`（大字金句）+ `lead`（解释段）+ `source-line`（真实引语才配这个，标注出处）。
- **账本 ledger**：3-5 行时间线/清单，每行 `ledger-nb`（年份/序号）+ `ledger-title`（事件）+ `ledger-note`（一句注释）+ 右侧 `meta` 短标签。适合"生平档案""转折三部曲""战绩清单"这类内容。
- **图文三明治**（配真实截图/照片时的默认结构）：**标题在上 → 图片居中 → 文字在下**。不要把图片和标题顺序颠倒，也不要把说明文字放在图片上方——读者的阅读顺序应该是"先看标题被吸引→看图印证→读文字补充细节"。
  ```
  kicker
  pullquote 或 h-xl（标题/金句）
  figure.work-fig（图片 + img-cap 图注）
  lead（补充说明）
  source-line（可选，图片来源真实引语时用）
  ```
- **左右分栏 split-lr**：仅在图片天然是竖版、且需要与一段较短的解读文字并排时使用（如手写笔迹配翻译）。`grid-template-columns` 按图片实际比例定，图片列通常 300-420px，文字列吃剩下的空间；`align-items:start` 让两列顶部对齐，不要用 center（矮的一列会显得没头没尾）。这个版式不如"三明治"直觉，只在图片本身适合竖版特写时才用，多数横版截图应该用三明治结构而非分栏。

## 收尾页（最后一张）

必须在**卡片图片本身**里印上品牌落款，字号 28px 左右，居中放在 `issue-strip` 上方，不要只写在配文文字里而卡片图是空的——这是过去所有系列都漏掉、后来专门补上的一条规则。**2026-07-30起，落款只写"审美创意局"四个字，不要写完整 slogan**（"用设计的眼睛，看懂世界的美"这句话放在卡片图里会显得违和，完整 slogan 留给配文文字用即可）。

## 图片规范

- **人物封面照默认彩色**，不做黑白/duotone 处理，除非人物本身的美学身份就是黑白极简风格（如川久保玲），或者是纪念/悼念类主题（黑白显庄重）——这两种例外要主动想清楚理由，不能图省事默认转灰度。见 `image-sourcing.md`。
- 选照片要选"好看/有亲和力"的那张：近景（不是舞台远景剪影）、表情自然（微笑或专注但不别扭）、光线均匀、分辨率经得起放大到 900px 宽以上不糊。多个候选就选最耐看的，不要图省事随手抓第一张能下载的图。
- 图表/截图类素材（评测榜单、访谈截图、官网截图）用户如果直接提供，**文案要按截图里实际显示的数字重写**，不要跟自己此前调研到的另一个不同榜单的数字混用——不同评测体系的分数不能互相替代或对比。
