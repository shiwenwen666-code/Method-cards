# 人物选题判断标准 · v2.0

## 选题范围与检查顺序
默认关注企业家、AI/科技人物、艺术家与有真实影响力的文化人物；用户明确指定选题优先。微信公众号图文帖以**人物本人**的真实故事和可借鉴方法为核心，不能为了热搜扩成泛娱乐或把所有人物强行联系穿搭、审美和品牌。

1. 查看已有项目/发布清单，避免重复；无法访问时如实说明，不凭记忆声称未做过。
2. 搜索人物当下新闻、争议及澄清，严格区分官方事实与传言。
3. 用**认知度 × 话题度 × 内容证据强度**判断：是否有可信的经历、转折、决策、方法可写。
4. 选取反常识/对仗/明确立场的传播切口，兼顾热点时效，但绝不能为了赶时间跳过事实核查。
5. 搜索高传播公众号文章时记录可核实的阅读、互动或传播指标；无法证明阅读量时不能冒称「10万+爆款」。吸收选题结构，不复制他人观点或文字。

过去个别内容的高阅读量只能说明单期表现，不足以证明「追热点必然增长」；须持续复盘预测与数据。

## 人物故事与方法论
用「处境 → 行动/选择 → 结果 → 原因与边界」串联，一项原则尽量配一个真实事例。避免没有依据的因果、重复的万能长期主义鸡汤。人物低认知度时，通过广为人知的产品、事件、作品或获奖事实作为认知桥梁，不要求读者事先认识本人。

## 女性主角写作边界
不以其与某位男性名人的关系、婚恋或对比来定义主角。优先写她本人的工作、作品、能力与选择；「首位」「唯一」和性别成就须核实限定范围。未经证实的外貌/性格评断不作为方法论。

## 封面和配文的区别
封面讲一句短而有力、可被正文事实支撑的中心论点；公众号配文标题是「人名｜不同角度的 Hook」，20字符以内。两者都不能假托人物名言。观点要犀利但不靠虚构反转。
